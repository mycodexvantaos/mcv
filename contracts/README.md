# Contracts

API contracts, event contracts, schemas, and resource definitions for MyCodexVantaOS.

## Structure

| Directory    | Description                              |
| ------------ | ---------------------------------------- |
| `openapi/`   | REST API contracts (OpenAPI 3.x)         |
| `events/`    | Event contracts (CloudEvents / AsyncAPI) |
| `schemas/`   | JSON Schema definitions                  |
| `resources/` | Resource kind definitions                |
| `asyncapi/`  | AsyncAPI event specifications            |
