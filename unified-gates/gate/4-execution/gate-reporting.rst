==============
Gate Reporting
==============

:Version: 1.0.0
:Status: normative

Report Types
------------

The gate system produces the following report types:

.. list-table::
   :header-rows: 1
   :widths: 35 65

   * - Report
     - Description
   * - ``gate-validation-report.json``
     - Per-pipeline run gate evaluation results. All gates, all layers.
   * - ``gate-coverage-report.json``
     - Coverage metrics across all 11 coverage dimensions.
   * - ``ai-infra-gate-report.json``
     - AI infrastructure gate results (l00–l90).
   * - ``gate-waiver-report.json``
     - Active waivers, expiry dates, and approver records.
   * - ``gate-audit-report.json``
     - Audit chain integrity report.
   * - ``production-closure-report.json``
     - Final production readiness report (l90 gates).
   * - ``unified-gate-summary.json``
     - Aggregated summary across all planes and layers.

Report Generation
-----------------

Reports are generated by ``scripts/generate-gate-report.py`` and
``scripts/generate-production-closure-report.py``. Reports MUST be generated
after every pipeline run and stored in ``outputs/``.

Report Schema
-------------

All reports conform to ``schemas/gate-result.schema.json``. Reports include:

- ``generatedAt``: ISO 8601 UTC timestamp
- ``pipelineRunId``: UUID v4
- ``overallStatus``: PASS | FAIL | WARN | BLOCKED
- ``layerResults``: Per-layer gate results
- ``evidenceSummary``: Hash counts and chain integrity status
- ``waiverSummary``: Active waiver count and expiry warnings
