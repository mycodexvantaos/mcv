# v0.1.1 — Dependency Vulnerability Remediation

**Release Date:** 2026-07-20
**Type:** Security Patch
**Scope:** Issue #81 — Dependabot vulnerability alerts

## Summary

Targeted security patch release addressing 10 of 20 Dependabot vulnerability alerts. No feature changes, no architecture changes, no breaking changes.

## Vulnerability Status

| Metric | Before | After |
|--------|--------|-------|
| Total vulnerabilities | 20 | 10 |
| High | 4 | 4 |
| Moderate | 14 | 5 |
| Low | 2 | 1 |

All 10 remaining vulnerabilities are DEFERRED with documented accepted risk and migration paths. See `docs/security/dependency-vulnerability-remediation-v0.1.1.md` for full details.

## Changes

### Direct Dependency Upgrades

- `wrangler`: `^3.99.0` → `^4.88.0` (in `apps/api-worker`) — resolves 5 undici vulnerabilities
- `ws`: `^8.16.0` → `^8.20.1` (in `services/mycodexvantaos-ai-team-service`) — CVE-2024-37886

### Transitive Dependency Overrides (pnpm.overrides)

- `esbuild`: `^0.25.0` — dev server request smuggling
- `postcss`: `^8.5.10` — XSS via unescaped `</style>`
- `protobufjs`: `^7.5.8` — prototype pollution
- `brace-expansion`: `^5.0.6` — ReDoS
- `ip-address`: `^10.1.1` — ReDoS/XSS
- `cookie`: `^0.7.0` — name injection
- `@modelcontextprotocol/sdk>hono`: `4.12.19` — JWT bypass
- `ajv>fast-uri`: `3.1.2` — ReDoS
