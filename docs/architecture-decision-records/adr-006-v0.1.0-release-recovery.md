# ADR 006: v0.1.0 Release Recovery Strategy

**Date**: 2026-05-20
**Status**: Accepted
**Context**: GitHub Release Immutability Record (GH013) blocks original tag name

## Context

The official `v0.1.0` release tag is blocked by GitHub's Immutability Record (GH013), an internal database record that persists even after releases are deleted and the "Enable release immutability" setting is disabled. This record locks the exact tag name `v0.1.0`, preventing any recreation of the tag or release.

After disabling Release Immutability and deleting the stale releases for `v0.1.0.0` and `v0.1.0-test`, the tag names `v0.1.0` and `v0.1.0.0` remain blocked by GH013. Attempting to recreate either tag fails with:

```
error: Cannot create ref due to creations being restricted
```

The tag `v0.1.0-stable` was successfully created at commit `1371a8966c3047bbd95e87308a0bc81e6b72bb41` and a GitHub Release was created with all 7 release artifacts uploaded.

## Decision

1. **Fallback Path Activated**: Use `v0.1.0-stable` as the official recovery publication tag.
2. **Product version**: 0.1.0 (unchanged).
3. **Publication tag**: `v0.1.0-stable` pointing to `1371a8966c3047bbd95e87308a0bc81e6b72bb41`.
4. **Constraint**: Do not use `v0.1.0.0` (wrong commit, blocked by GH013).
5. **GitHub Release**: Created at `v0.1.0-stable` with all 7 release artifacts uploaded.

## Release Metadata

```json
{
  "product_version": "0.1.0",
  "intended_tag": "v0.1.0",
  "publication_tag": "v0.1.0-stable",
  "source_commit": "1371a8966c3047bbd95e87308a0bc81e6b72bb41",
  "recovery_reason": "original tag v0.1.0 locked by GitHub internal release immutability record (GH013)",
  "tag_type": "recovery_publication"
}
```

## Consequences

- **Positive**: Release publication is unblocked; all artifacts are available at `v0.1.0-stable`.
- **Positive**: Supply chain integrity is maintained (same commit, same artifacts).
- **Negative**: Tag name differs from product version (v0.1.0-stable vs 0.1.0).
- **Negative**: Documentation must be updated to reference `v0.1.0-stable` as the publication tag.
- **Mitigation**: Clear distinction between `product_version` (0.1.0) and `publication_tag` (v0.1.0-stable) in all documentation.
