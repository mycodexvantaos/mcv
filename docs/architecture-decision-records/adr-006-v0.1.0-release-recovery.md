# ADR 006: v0.1.0 Release Recovery Strategy

## Status

Proposed

## Context

The official `v0.1.0` release tag is blocked by GitHub's Immutability Record. A temporary tag `v0.1.0.0` was created but points to the wrong commit (`e35af2a`), which breaks the supply chain provenance linked to the stable artifacts at `1371a89`.

## Decision

1. **Primary Path**: Request GitHub Support to clear the immutability records for both `v0.1.0` and `v0.1.0.0`.
2. **Fallback Path**: If records cannot be cleared, use `v0.1.0-stable` as the official tag name.
3. **Constraint**: Do not use `v0.1.0.0` in its current state as it violates the supply chain integrity of the v0.1.0 artifacts.

## Consequences

- Requires manual intervention from GitHub Support.
- Ensures the official release tag matches the verified artifacts and provenance.
- Prevents technical debt associated with incorrect tag-to-commit mappings.
